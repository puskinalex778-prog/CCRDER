# NFC PAY — Офлайн-симулятор NFC-терминала (Android)

Развлекательный офлайн-симулятор приёма платежей, обратного зачисления и чтения открытых данных NFC через Android NFC Reader Mode.
Приложение **не выполняет настоящие платежи**, **не списывает и не переводит деньги**, **не подключается к интернету** и **не формирует банковские чеки**.

## Версии в репозитории
- **v1.0.0** (ветка `v1-basic`, тег `v1.0.0`): базовая версия терминала — «Получить платёж», «Демо без NFC», согласие владельца карты, ожидание 30 сек., история и настройки звука/вибрации.
- **v2.0.0** (ветка `main`, тег `v2.0.0`): расширенная версия — всё из v1.0.0 + **обратная отправка («Отправить на карту»)** + **Сканер NFC-данных** (чтение, сохранение и просмотр открытых данных NFC-меток и карт).

## Технологии
- **Kotlin 2.0**, **Jetpack Compose**, **Material 3**
- **Архитектура:** MVVM + однонаправленный поток состояний (`StateFlow`)
- **Минимальная версия Android:** Android 9.0 (API 28) и новее (`targetSdk = 35`)
- **NFC:** Android `NfcAdapter.enableReaderMode`
- **Офлайн:** разрешение `android.permission.INTERNET` отсутствует в `AndroidManifest.xml`

## Сборка APK через GitHub Actions
Workflow `.github/workflows/build-apk.yml` автоматически запускается для `main`, `v*`-веток и тегов `v*`:
- прогоняет unit-тесты (`gradle testDebugUnitTest`);
- собирает `NFC-PAY-v<версия>-debug.apk` и `NFC-PAY-v<версия>-release-unsigned.apk`;
- прикрепляет готовые APK во вкладку **Actions → Artifacts** и в **Releases** (для тегов `v1.0.0` и `v2.0.0`).
