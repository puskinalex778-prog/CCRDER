# NFC PAY — Офлайн-симулятор NFC-терминала (Android)

Развлекательный офлайн-симулятор приёма платежей через Android NFC Reader Mode.
Приложение **не выполняет настоящие платежи**, **не списывает деньги**, **не подключается к интернету** и **не формирует банковские чеки**.

## Технологии
- **Kotlin 2.0**, **Jetpack Compose**, **Material 3**
- **Архитектура:** MVVM + однонаправленный поток состояний (`StateFlow`)
- **Минимальная версия Android:** Android 9.0 (API 28) и новее (`targetSdk = 35`)
- **NFC:** Android `NfcAdapter.enableReaderMode` (только стандартное открытое чтение совместимых карт после явного согласия владельца карты)
- **Офлайн:** разрешение `android.permission.INTERNET` отсутствует в `AndroidManifest.xml`

## Сборка APK через GitHub Actions
В проекте настроен workflow `.github/workflows/build-apk.yml`.

### Пошаговая инструкция:
1. Создайте пустой репозиторий на GitHub (например, `nfc-pay-simulator`).
2. Загрузите содержимое папки `nfc-pay` в ветку `main`:
   ```bash
   git remote add origin <URL-ВАШЕГО-РЕПОЗИТОРИЯ>
   git push -u origin main
   ```
3. Откройте вкладку **Actions** в репозитории GitHub — автоматически запустится workflow **Build NFC PAY APK**.
4. Workflow последовательно выполнит:
   - запуск unit-тестов (`gradle testDebugUnitTest`);
   - сборку `NFC-PAY-debug.apk` (готов к установке на Android-смартфон);
   - сборку `NFC-PAY-release-unsigned.apk`.
5. Скачайте готовый APK из раздела **Artifacts** завершённого запуска (или создайте git-тег `v1.0.0`, чтобы APK автоматически прикрепился к **GitHub Releases**).

## Чек-лист проверки безопасности и приватности
- [x] **Отсутствие сетевых запросов и разрешений:** в `AndroidManifest.xml` нет `INTERNET`, `ACCESS_NETWORK_STATE`, `ACCESS_WIFI_STATE`; в проекте нет HTTP-клиентов, SDK аналитики, рекламы и банковских API.
- [x] **Отсутствие сохранения платёжных реквизитов:** `SharedPreferencesHistoryRepository` сохраняет только сумму (`amountKopecks`), время (`timestampMillis`), статус (`"Завершенные платежи"`), флаг режима без карты и открытое техническое описание (`openCardInfo`, например `"Бесконтактная карта · IsoDep (EMV)"` или `"Без считывания карты"`). Ни полный PAN, ни последние 4 цифры, ни срок действия, ни CVV, ни Track 2 на диск не записываются (`android:allowBackup="false"`).
- [x] **Отсутствие чувствительных логов:** в исходном коде отсутствуют вызовы `android.util.Log` и `println` для APDU/TLV/номеров карт; дополнительно в `proguard-rules.pro` добавлено вырезание вызовов `android.util.Log` в release-сборке.
- [x] **Явное согласие до активации NFC:** `NfcReaderController.startReading()` вызывается исключительно при `TerminalUiState.WaitingForCard` и только после нажатия кнопки «Разрешаю чтение моей карты». В `AndroidManifest.xml` отсутствуют авто-запускающие NFC intent-filters.
- [x] **Безопасный жизненный цикл NFC:** при уходе с экрана ожидания, таймауте 30 сек., отмене, сворачивании приложения (`onPause`) или получении первого тега `disableReaderMode` вызывается немедленно; повторные срабатывания блокируются через `AtomicBoolean` и проверку состояния ViewModel.
- [x] **Только стандартное чтение без криптограмм:** `EmvPublicDataReader` не отправляет `GENERATE AC` (`80 AE`), не запрашивает PIN и не выполняет аутентификацию карты.
- [x] **Без поддельных чеков:** экран результата не генерирует банковский чек, платёжное поручение, фальшивый ID транзакции и не содержит кнопки экспорта подтверждения оплаты.
